## 两条研究线分别成立

**M：关系条件寻址机制。** 恢复“参照绑定 → 关系条件计算 → 目标地址 → 属性读取”的
原生依赖，预测未参与拟合的中间响应与错误。优先假说是视觉端提供场景地址结构，语言端
执行关系条件的地址变换；候选比较和邻接读取也是需要正面解释的可能结果。

**S：联合干预集合搜索。** 对同一图像、多种问题，在固定层搜索共同的原生视觉 K-cache
替换集合；利用精确注意力响应、分式代理求解和真实下游反馈，争取更好的效果—成本关系。

M 不以 S 成功为前提；S 的收益也不证明 M 的具体机制。两者共用基础设施，不预设合为一篇论文。

## 怎么维护

- 文献原始事实及复用边界集中放在 02；其他章节链接它，不复制一套论文列表。
- 接口与符号变动先更新 03，再同步假设、推导、实验与记录字段。
- 推导放在 04/05；参数选择、数据划分和验证方法放在 06。
- 07 只写有依据的研究判断，并链接对应运行；原始指标保存在 run 产物或 tracking 系统。
- 每条结论说明属于“作者报告”“推导”“工作假说”“计划”还是“本项目实测”。
- 一个方法被否定时，更新该方法及相关假设；保留仍有价值的父问题和下一步。
