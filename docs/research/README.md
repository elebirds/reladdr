## 两条研究线独立验收

**机制线：**真实参照／关系输入→组合写入→完整候选竞争→属性写入。
纯地址、单头、仿射形式均非前提；多位置、候选比较和预存字段可成为结论。
首批先用已有 pre-O/MLP 消费写入定位及确认，再补选定读取器的观测；
M06 与 M07 的竞争预测／辨识形成小循环，不等全部定位完成。

**搜索线：**同图多问、固定原生视觉K-cache的联合干预集合搜索，评价真实效果—总成本。
搜索收益不证明机制，机制反例也不由搜索收益弥补。
