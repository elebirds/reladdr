# 实验设计：每组比较回答一个研究问题

当前已完成一次三形状 [GPU 工程初调](../reports/gpu_smoke_2026-10-19.md)，取得可追溯的
逐样本结果。正式划分与网格覆盖、下述机制和搜索实验仍按本页协议继续实现。运行身份和记录约定见 [08](08_resources_and_reproducibility.md)。

## 共用数据与评价规则

### 主任务语义

原任务沿用 [R1 §4.4](02_related_work.md#r1) 的直接 above/below/left/right 关系颜色读取。
先用 [R3](02_related_work.md#r3) 的三个对象横/竖场景复现基础现象，再增加参照位置可变的
二维网格，计划以 4×4 为主并检查密度造成的识别难度。

对每种布局明确“直接相邻”的唯一性和有效边界；像素距离、同行最近对象与相邻格属于
不同语义。空位、非均匀间距、不规则布局作为单独标记的泛化/反例条件，不反向改写主任务。
生成器保存 object ID、属性、bbox、布局、reference ID、target ID 和关系真值。

同图配对象识别、直接位置读取、关系条件属性读取三类问题。错误对象不能只从重复颜色
倒推：可区分属性不足时记录候选集合，或借助声明的内部地址读出，而不强判唯一误选对象。

### 划分和统计

- discovery 用于候选层/头和基的发现；validation 用于维度、幅度与搜索超参数；test 只做最终检验。
- 同图多问与原图的换色/镜像等变体按 scene-family 分组，不跨上述集合。
- 留出参照—关系组合、新对象属性与布局条件；不能只随机拆问题行。
- 报告全量表现，也可单列原模型正确样本的因果分析；同时给出该子集数量与覆盖，不能替代全量结果。
- 同场景问题相关，误差区间/成对比较以 scene-family 为重采样单位；报告种子和配置。
- 数据量先用于检查实现与效应尺度，再依据场景级不确定性和目标精度扩充，不设未经依据的统一通过阈值。

## E01 · 原模型任务基线与图像依赖

**问题**：识别、直接位置读取、关系选址哪一步已能完成？行为是否依赖当前图像？

**比较**：原图与同尺寸空白/真实错配图，固定模板；对象位置交换、属性交换与关系/参照变化。
选择题若用于控制命名，交换选项顺序；开放颜色回答使用固定读出协议。参照先于关系与
关系先行模板分别报告，不能把模板变化造成的算法差异并入同一个结果。

**输出**：准确率、固定 correct/foil 的 margin、逐关系/模板/布局切片、成对一致性、
实际 token 长度和成本。先验证标注与候选 tokenization，再定义算法线的下一 token 目标。

**改变的行动**：识别失败时先定位图像/标注/模板和感知难度；基线稳定后进入机制解释。
某个方向表现较差时保留事实，不把最强方向偷偷改成全部研究问题。

## E02 · 位置 ID 与读取来源的学习性复现

**问题**：前作的地址与读取接口在当前固定模型/版本上能恢复到哪一步？

1. 按 [R2](02_related_work.md#r2) 的内容中心化/跨对象平均提取空间成分，做属性变化对照。
2. 按 [R1](02_related_work.md#r1) 比较原型 ID、head-level patching 和属性读取接口。
3. 按 [R3](02_related_work.md#r3) 比较视觉条带和文本侧状态，检验地址结构来源。
4. 将 [R5](02_related_work.md#r5) 的区域 attention 评分作为候选读取头定位工具，而非机制终点。

原任务的小规模复现和迁移到关系任务的结果分开。干预幅度、头数由 validation 确定；
论文原有最优参数/样本选择策略可另行复现，但不把 test 上选出的最佳值当泛化性能。
各组与等范数随机方向、同数量随机头，以及同位置换内容条件比较。

**输出**：ID 的可读性、跨内容稳定性、因果 donor 效应、读取 query 和 OV 写入证据。
论文中的层号只作候选，不硬编码为当前模型已经定位出的事实。

## E03 · 恢复参照到目标地址的原生计算

**问题**：共享关系算子能否解释和预测模型真正执行的地址形成？

### E03a：先固定输入、输出和剩余路径

按 [03](03_interfaces_and_notation.md) 定义 $B_{\mathrm{ref}},R,E,U$；至少保留一个参照先行
模板，在关系未出现的位置读取参照状态。地址基由独立数据标定；保留 $E$ 与其他路径。
先在同图内比较，跨图时再检查绝对位置、场景序号和其他相对编码。

### E03b：小模型解释的必要性比较

在相同接口和留出协议下比较共享加性 $AR+c_\rho$、关系仿射 $A_\rho R+t_\rho$，再按
反例检验场景依赖。固定低维接口，避免利用自由的高维矩阵记住位置标签。

报告中间状态预测、目标地址识别与候选 QK 分差，而不只报重建误差。
仿射比加性更强时，进一步寻找实际执行它的原生路径；两者同样好则保留简单解释。

### E03c：追踪第一次地址写入，而不是 probe 峰值

围绕三个不同的因果预测取证：

- **在线变换**：关系条件组件在候选读取之前将参照成分写成目标地址。
- **候选比较**：query 仍携带参照阈值，候选 QK 竞争后由 OV 写出目标地址。
- **邻接读取**：参照读取取到已编码邻居，再按关系选择字段。

定位步骤从实际 QK 分差和写入贡献逆向到输入；可用头/MLP 局部屏蔽及 donor 恢复检查
所声明路径。必要性消融与局部恢复分别说明，重算后续受影响状态。完整状态互换可能带入
身份、答案或整个场景，要用地址/内容对照审查，不能只凭答案翻转命名“规则迁移”。

“第一次”只在已检查并验证的路径内成立；若路径不可分离，记录未识别依赖，不强行分类。

### E03d：共享结构的留出预测

检查未拟合参照—关系组合、对象/属性替换和整体布局变化。共同地址空间已标定后，再检查
合法区域的逆关系/交换律，以及混合地址的中间写入预测。混合离分布效应与自然样本分开。
用地址方向的 JVP/VJP 检查候选原生组件是否与拟合映射一致。

**关键产物**：同一解释对自然执行、有限 donor 干预后的 QK/写入/读取，以及自然错误的
联合预测。能否把错误归入参照绑定、关系计算或属性读取，构成机制解释的实际价值。

## E04 · 同图多问的联合 K-cache 集合搜索（独立研究线）

**问题**：精确联合注意力响应是否帮助找到更好的真实干预集合，且值得其求解成本？

### E04a：端口和解析等式核对

只做固定层、post-mRoPE/pre-GQA 的原生 K 槽位替换，保留 V。使用位置编号匹配的固定 donor；
覆盖所有受影响头和 suffix 行，接回原生下游。检查 no-op、缓存恢复、GQA 所有读取者、
重算范围和解析 $Y$ 与原生 $Y$ 的误差；不把末行代理当完整充分接口。

### E04b：代理求解能力

在相同原生缓存系数上比较独立下界、残差线性界、必要的响应耦合、通用分式求解路线。
只在少量小实例上穷举核对最优值与证书，不把全数据穷举作为统一前提。

报告代理值、有效上下界、最优性间隙、节点/迭代量和 CPU 时间。
分析分母范围/实际 $\eta$、精确重复项比例与共同选择代价；不能只按最优集合重合率解释收益。

### E04c：真实行为的强基线

| 基线 | 具体作用 |
| --- | --- |
| 随机大小 k 集合 | 基本破坏效应和成本参照 |
| AtP* 单项 top-k | 强单项非线性修正 |
| 真实条件贪心 | 每步在当前集合上计算真实边际效果 |
| 条件贪心＋1-swap | 排除常规局部修正已足够 |
| 连续 K 替换掩码优化后离散化 | 联合梯度优化的适配基线，按同一 donor 和 k 计费 |
| 相同外层＋可加代理 | 隔离普通反馈迭代与精确分式结构的贡献 |
| 残差界联合搜索＋真实反馈 | 本项目待验证方法 |

连续掩码可通过原 key/donor key 插值构造训练松弛，但对最终离散集一律用同一原生替换
评价；松弛期间的 forward/backward 计入成本。迭代 AtP* 和掩码优化是本项目适配，不能
冒称原论文已在该缓存端口做过完全相同的算法。

所有方法共用图像/问题、候选组、donor、k、固定权重/foil、可用的前缀缓存和后端。
比较效果—真实下游调用与效果—总时间两条曲线，而非要求所有不同成本单位同时相等。
用一组小到大的有效 k 分别求解；不同 k 的最优集合不预设嵌套。

**输出**：$J(C)$ 与逐问 margin 变化、答案翻转率、代理到真实改善转化、失败提案、
局部停滞、峰值显存、CPU/GPU 各阶段成本。原模型正确/错误问题分开切片，避免把已有
错误的 margin 下降叫作新的正确答案破坏。该搜索度量敏感性，不自动建立共享机制语义。

## E05 · 外部与跨模型边界（首批机制结果后的扩展）

优先承接 R3 的 What’sUp 三对象合成设置，保持“参照→目标对象”的任务结构。
COCO-spatial 的关系识别是补充外部有效性，不替代目标地址生成；需要新标注的属性问题
要说明其构造和歧义处理。

第二模型用于检验机制/方法适用条件，不在第一轮堆满模型榜单。新模型重新定位地址接口和
原生端口；不同基底和 head 编号不直接复用。自然图片不能满足的精确反事实干预应保留为限制。

## 实施顺序

第一条可运行链路只完成 E01：场景/问题真值 → 固定模型推理 → 逐样本结果 → 汇总报告。
随后推进 E02/E03。E04 是独立验证，不阻塞机制线；E05 在有具体可迁移发现后展开。
阶段结果按 [07](07_outcomes_and_decisions.md) 更新，不把“完成一次运行”当成完成一个科学问题。
