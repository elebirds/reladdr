# 预期结果与研究决策

已取得一次 [Instruct 工程初调结果](../reports/gpu_smoke_2026-10-19.md)：单场景族的原图、
空白和换色对照可执行，逐问输出已保存。正式多场景族 E01 尚待补齐，机制与算法假说保持
下表状态；下一步先扩展数据与划分，再按既定判别实验取证。

## 1. 值得追求的交付

### 机制线

一段可追踪的原生计算解释：参照空间信息怎样在关系条件下改变候选分数、形成目标地址，
并被属性读取使用。理想结果能跨留出组合预测中间响应与错误；如果实际路径依赖场景、
预存邻接或候选竞争，清楚恢复该路径同样推进原问题。

### 搜索线

一个接口语义明确、真实效果—成本更好的联合集合求解方法。需要同时给出解析响应正确性、
代理求解质量、真实下游转化，以及包含 CPU 和失败提案的成本。
只得到正确公式、代理最优或单例优于贪心，均不等于已取得现实效率收益。

## 2. 假设与反证如何改变下一步

| 对象 | 目前状态 | 支持证据 | 反证后的行动 |
| --- | --- | --- | --- |
| M1：参照读取有可用空间成分 | 假说；有前作方法基础 | 跨内容 ID 与因果替换成立 | 检查表示混合和场景相对编码，保留完整读取状态 |
| M2：共享关系仿射变换 | 假说 | 留出预测优于简单解释，且匹配原生写入/响应 | 若加性同样好则简化；若场景必要则解释实际依赖 |
| M3：门控 MLP 是主要执行位置 | 实现猜想 | 原生路径、方向导数与有限干预相符 | 转向实际 attention/分布式路径，不否定关系问题 |
| M4：预编译地址＋在线变换 | 首要结构假说 | 视觉地址结构与语言条件计算分别有证据 | 比较候选竞争、邻接读取；等价描述合并 |
| S1：声明端口的分式等式 | 条件推导，待数值核对 | 完整接口解析与原生重算一致 | 先修正端口、mask、GQA 或重算范围，不解释为模型现象 |

确定，test 冻结检验。

## 3. 哪些负结果仍然有信息

- 线性可读但干预无预测力：该表征不能据此被命名为当前计算变量，继续检查原生依赖。
- 共享偏置足够：说明没必要引入关系特定矩阵；以较小机制解释保留有效发现。
- 地址取决于场景：把坐标系/候选路径纳入机制，不为每图自由对齐后宣称共享。
- 目标地址主要由候选 OV 写出：解释比较—再绑定链，不坚持必须在 query 中预生成地址。
- 求解器代理更优但真实目标不变：下游近似是当前瓶颈；代理证书不外推。
- 普通贪心/1-swap/连续优化已足够：撤回需要专用联合求解的强主张，保留有效适用边界。
- 分式结构只在局部接口有用：按局部分析任务评价，不宣称全图电路发现加速。

## 4. 已作出的项目决定

截至 2026-10-19，以下属于研究和工程选择，不是性能结果：

1. 项目名 RelAddr，机制研究与集合搜索分开验收。
2. 首个分析模型 Qwen2-VL-7B-Instruct；已用冻结参数、BF16 完成工程初调。
3. 直接方向关系和目标唯一场景优先；参照可变的二维任务用于检验动态依赖。
4. 机制先比较共享加性与关系仿射解释，原生 MLP/头由证据定位。
5. 搜索端口为同图多问、固定层、原生 post-mRoPE/pre-GQA K-cache，K-only、固定 donor。
6. 不先训练替代下游；保留完整接口并优先使用原生下游与真实反馈。
7. uv 管理依赖；MLflow 参数/指标同步已独立实测，GPU 初调关闭 Tracking 与 OSS。
8. 公共运行层、三形状生成器与推理适配器已实现；正式划分、网格、激活干预和搜索实现继续推进。
