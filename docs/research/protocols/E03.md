# E03：从可迁移状态到关系条件的原生计算

## E03a v1：先排除“只搬运了方向指令”

2026-10-20。E02 首批已在真实 readout 端口恢复中层位置响应和晚层属性响应。
但 E02 donor 同时改变图像属性和方向，完整残差可能只搬运了方向指令。
E03a 先检验这个更便宜、能改变后续方向的替代解释。

**主比较**：recipient 与 donor 使用逐字相同的提示、同一关系和参照颜色；
recipient 参照在中间，donor 参照移到合法边缘。三个结果仍两两不同：
接收图原答案 a、接收图 donor 目标位置的属性 b、donor 自身答案 c。
例如关系均为 left；donor 参照移到右端，则 donor 目标在中间，b 是接收图的中间颜色。

沿用 E02 前作几何/调色板与原生端口，两方向各一对/族；8个 discovery 族，共16对。
全部28层、readout 与问题末词分别报告。所有 E02 已分配图像预先保留，新增 donor 不与其他
族的 clean/donor 图像重复；未执行 validation/test。源码入口 `reladdr.experiments.e03`，配置 `e03a.yaml`。

### 结果怎样改变工作

1. 同指令情况下仍有可重复的 b 响应：排除仅迁移方向文字，支持把该阶段作为目标选择端口继续 E03b。
2. 只有 c 响应，或 b 窗口不能迁移：E02 的地址解释适用范围需要收缩，先分离参照/指令及地址。
3. 原图 donor 基线失效：只能在有明确覆盖的正确子集解释，不能把任务失败算作地址机制反证。

这一步测试“已有端口是什么”，不以改变参照的题目数量充当新机制。
后续 E03b 从确认过的选择端口逆向追踪 attention/MLP 与候选信息；
E03c 只解释已经定位的原生路径；E03d 用未拟合条件检验冻结解释。


## E03a v2：明确相邻语义，纠正 v1 扩展的歧义

v1 的原句 left/right of 在 donor 边缘参照时允许多个对象。实际观测到 donor 常选择最远端；
该批不据此反驳地址机制。保留原始 run 与 `e03a_directional.yaml`；入口仍可按明确 v1 重现。
v2 在两个输入的同一句提示中加入 immediately，明确只取相邻对象，其他图像、配对和标签不变。
主配置 `e03a.yaml` 声明 e03a-v2；逐字相同的问题约束保持。

## v2 后的接口充分性核查

Discovery 中14/16对双端正确，但 readout 全28层未出现一次 b 的 greedy 迁移；
不能把这直接解释为整个网络没有地址计算。针对当前单 token 端口的三项核查为：

1. `E02/e02-adjacent-v1`：相同 immediately 措辞下，原来的左右方向切换是否仍有 b 窗口。
2. `e03a_reverse.yaml`：逆转 donor/recipient，按真值排除反向三个标签重叠的配对，完整记录排除清单。
   原8族中13对可区分，不按模型输出挑样本；其双端正确覆盖另列。
3. `e03a_suffix.yaml`：除 readout 外，替换全部视觉 token 之后的后缀状态，含 vision_end 与
   完整问题/assistant 标记；重算后续网络。不是只修改最后一步或修改缓存。

多位置检查在第一对先做完整序列状态移植，应精确恢复 donor logits（容差0.01），再解释 suffix 结果。
此正对照只确认端口实现，不证明任何地址机制。各实际端口的自身替换和恢复检查继续执行。

若匹配措辞仍有 E02 窗口、但同指令下两方向/完整 suffix 均不能转移 b，则撤回
“将该 readout 全状态直接当作跨参照可复用目标地址”的推进前提；不进入据此拟合共享仿射算子。
输入/输出的其他原生路径以及纯子空间仍待重新定位，不由负 patch 宣称其不存在。

## E03b-mediation-v1：沿实际恢复的路径定位

完整 suffix 在第18层使正确子集9/14对转向 b，推翻“单 readout 失败即可否定整个地址路径”的解释。
因此继续定位，而不是停在负结果：用实际 token 索引把 suffix 分成 vision_end、参照描述、
参照后的问题尾部、assistant边界/标记、关系词、其他词六组。分组互斥、覆盖完整 suffix。

每组两种替换：
- group_only：只移入该组 donor 状态，检验恢复是否充分；
- full_except_group：移入完整 donor suffix，再恢复该组 clean 状态，检验该组对已观察恢复是否必要。

Discovery 固定层16–20，来自已经观测到的 suffix 恢复区域；不把这组层号当冻结测试结果。
保持原16对，报告全量和双端正确子集；保存每组真实 token 文本及每层每对结果。
下一步由充分/必要证据决定追踪位置，不预设 MLP 或末 token 是执行位置。

## 冻结比较：留出族用于确认，不再选层

Discovery 分组结果：第17层恢复 clean 参照描述会把完整 suffix 的 b 恢复9/14降至0/14；
第18层单独恢复 clean 问题尾部或 assistant 组也都降到0/14，各组单独移入 donor 均不足。
因此当前数据支持多位置依赖，不能把 readout 失败解释为整个网络没有地址信息。

在查看留出模型结果前固定：
- E02 同措辞源任务：readout 第21层的 b、第24层的 c；
- E03a 同指令动态参照：readout 与完整 suffix，保留原全28层曲线，不用 test 另挑峰；
- E03b：固定第17、18层及原六组、两种中介替换；分别报告 validation/test。

三个固定配置为 e02_frozen、e03a_frozen、e03b_frozen。输入、提示、族划分、生成器均不改。
如果留出确认这个多位置依赖，撤回“可直接用最终 token 全状态充当通用独立目标地址”的
实验前提。它没有否定低维空间成分、候选比较或其他原生路径；这些需在改写接口假说后研究。

## E03a-grid-v1：排除三对象反例的标签重叠

一维正向控制的 donor 目标在中间，因此 b 总等于接收图参照颜色。正向 b 恢复可能混有参照
属性泄漏，失败也可能受参照排除影响；不能据此独立判定通用地址机制。
故回到原计划二维场景：2×2，四个颜色唯一，参照同色同形，问题逐字相同；每方向一对/族。
同关系下参照换到另一个合法行/列，donor 目标格既不是接收图原目标格，也不是其参照格。
要求 a、b、c 和参照色四者不同。固定336px、56px对象、144视觉token；图像束不跨族/划分重复。
先运行 discovery 8族32对，再冻结对照。配置 e03a_grid，入口 e03_grid。
它检验一维反例的可辨识性，不能把二维扩展本身当作贡献。

## E03b-conditional-freeze-v1：MLP 在线变化是否必要

沿原生端口检验一个具体架构猜想，而不是再拟合地址矩阵：同图分别改变关系或参照，
保留新问题的原生嵌入、视觉前缀与后续前向，但把声明位置的 MLP/attention 输出固定为旧问题值。
三个条件为全部文本 MLP、16–22层文本 MLP、全部文本 attention。文本不含 vision_end。
同时保留自然新问题基线，首次样本检查全部组件自身替换精确不变。

若冻结所有文本 MLP 的条件变化后仍保持新问题正确，而 attention 冻结失去新选择，说明
新选择不要求这些 MLP 写入随条件改变。它检验在线变化的必要性；既有常量 MLP 写入与
潜在备份路径仍保留，不能据此声称网络完全不使用 MLP。
关系变化先用三对象同图左右；参照变化用2×2同图同关系，源图不会一起改变。
MLP冻结若失败，不单凭失败推断其实现了地址变换。

二维 discovery 的双端正确覆盖19/32；readout 第21层 b 为8/19，完整 suffix 第17层为15/19。
它说明一维0迁移不能推广成“目标地址不存在”，同时单 readout 也没有覆盖完整路径。
按真值另列 b 在 donor 图像中完全不存在的切片，排除非目标 donor 属性泄漏；不按模型表现筛选。

冻结二维 readout第21层与suffix第17层、原MLP/attention冻结范围，在validation/test确认。
配置 e03a_grid_frozen、e03b_freeze_frozen；两者不再选层。
MLP冻结 discovery：两类条件的正确子集均在全部文本MLP冻结下丢失新答案；不能把这解释成
已找到地址变换，因为其中仍含属性读取和条件传播。下一步的原生模型必须区分这三种功能。
