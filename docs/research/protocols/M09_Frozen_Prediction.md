# M09_Frozen_Prediction — 冻结解释的新证据预测

状态：**计划；未实现、未执行**。仅在 [M08](M08_Local_Replacement.md) 交付可用解释版本后启动。
本节点检验同一解释，不再寻找最优层、头、维度、幅度或场景基。

## 科学问题与竞争解释

解释是否超出了已见场景和干预的记忆？它能否预测新的自然执行、原生局部响应与失败？
主要竞争解释是配色/场景过拟合、同一干预反复调优，以及替代模块只利用未解释旁路。

四对象六问已全部用于发现。正式验证使用 **fresh family + 未拟合的干预条件**，
不把重用六问的新图称为“未探索参照—关系组合”。

## 冻结清单与数据隔离

在读取测试结果前冻结并保存：

- 解释版本、真实输入提取、层/头/token、全部坐标与投影、参数、保留分量；
- 数据生成规则、族清单、全部自然问题、干预类型、donor 规则、预期效应和失败预测；
- 写入/评分/来源质量/OV/属性指标、基线、区间规则及 S/R/U/E 判据；
- 下游替代范围与实际模型/processor/dtype/backend/code 状态。

fresh family 必须与 B03、M04–M08 以及已有历史 run 的图像和派生变体隔离。
初批 B03 16 族及其条件性追加族都属于发现数据，不挪作正式冻结集。
使用独立的冻结族命名/seed 清单；族生成器须记录与旧 manifest 的实际重合检查。

至少保留一种在 M05–M08 未用于拟合或选择的原生干预条件。具体条件由已经形成的解释
给出，例如独立配色的同位置 donor、尚未拟合的有向输入变化或已声明的联合输入变化；
它若已被前序节点查看，就不再满足未拟合条件，不能只换名字。

未来若确要主张未见参照—关系组合，必须另行预留可辨识的组合并明确其自然行为域；
本节点不据现有六问默认具备这一证据。

## 端口、操作顺序与指标

使用冻结原生端口和重算规则：

1. 按冻结规则取得解释函数的真实输入；可执行至该输入端，或隔离完整捕获中待评估的输出。
   不把下游真值响应或答案送给预测函数。
2. 保存每个新自然输入/干预的中间响应与行为预测，再读取待评估的原生响应。
3. 按冻结范围执行紧凑替代，比较完整中间链。
4. 全部错误按最早预测失败处分类，不只统计最终正确率。

指标沿用 M07/M08：写入误差、全允许来源的 score 误差、来源质量、OV 输出、属性 margin、
实际 greedy 输出及未解释效应。统计按场景族重采样，报告族数、自然基线覆盖和全量结果。
自然输入与混合干预分别报告；候选概率聚合不能替代 greedy outcome。

冻结前列明具有实质意义的容差：由 M03 数值误差与 M07 validation 中误差是否改变候选、
来源质量、属性结论共同确定，不能事后随 test 放宽。近零自然变化只报告绝对误差。
不要求所有指标都达到一个任意统一百分比，但支持主张必须覆盖其声称的计算链。

## S / R / U / E 出口

- **S — 支持**：冻结解释在新族与未拟合干预上预测同一中间链及行为/错误，适用范围和
  未解释贡献可量化；允许进入 [V01](V01_External_Validation.md)。
- **R — 反驳**：存在重复的方向性反例，或错误由模型遗漏依赖系统产生；
  撤回受影响的具体解释/范围，不因模型仍答对而忽略中间失败。
- **U — 不确定**：有效族覆盖不足、区间跨越决策阈值或干预离自然域；
  冻结版本不变，仅在追加族能解决该具体不确定性时扩量。
- **E — 合并**：竞争解释在新证据上仍原生等价，保留最小等价类，
  不新增无鉴别力场景来维持三选一。

## 有限回溯：只返回最早失配的环节

| 最早失配 | 返回对象 |
| --- | --- |
| 真实参照/关系输入未被正确描述 | M06 的绑定/输入边 |
| 输入已解释，局部条件写入预测错 | M06/M07 的组合函数 |
| 写入预测对，完整 score/来源质量错 | M03/M05 的端口或文本 K/V 条件 |
| 评分与来源质量对，OV/属性读取错 | M04 的读取路径 |
| 只在干预后改变路由 | M06 的 `parallel_and_backup_routes` |

已通过且输入条件未变的链段不重新全扫。查看过的失败族转为 development。
每个解释版本仅有一次针对最早失配的修订机会；修订后需新的冻结族和未拟合响应。
若仍必须不断追加任意高维输入或每图基，暂停该具体假说并记录 R/U，不能无限换 test。

## 工作量与终止

设 `F` 为 fresh family 数、`Q` 为每族自然输入数、`J` 为每族干预上下文数、
`C` 为冻结替代/控制条件数，登记上界 `F×(Q+J×C)`，并列自然捕获与新端口检查。
不先报一个总预算后把调参前向隐藏在验证内。是否追加族由预先声明的区间判据决定。

S 后停止主机制的调优，进入外部边界或成稿；E 后交付等价类。
R/U 时给出被否定的最小主张、保留的路径和明确恢复条件，不用新模型/新网格包装失败。
