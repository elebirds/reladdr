# M07_Compact_Explanation — 压缩已定位的原生计算

状态：**计划；本节点专用流程未实现、未执行**。
依赖 [M06](M06_Condition_Composition.md) 给出的真实输入、生产组件、消费端与未解释分量；
地址/坐标的统一契约见 [03](../03_interfaces_and_notation.md)。

## 科学问题与竞争解释

同一小函数能否解释原生局部写入及其条件响应？比较对象不是任意目标标签的预测器，
而是同一输入、同一输出端口下的：

- 不使用参照或不使用关系的简化基线，包括 B03 的方向选边界策略；
- 共享映射加关系偏置；
- 证据要求时才加入的关系调制映射；
- M06 证实的场景输入、预存字段或联合路径解释。

地址变换、候选评分、字段读取若在当前原生依赖上等价，作为同一个解释类比较，
不因公式名字不同重复算作竞争模型。假说公式的权威定义见
[04](../04_mechanism_hypotheses.md)，本节点不再另立一套符号。

## 拟合对象与可用输入

优先解释生产组件的实际写入 `m`；下游继续使用真实残差、归一化、Q/K 投影和 OV。
若 M06 只能确认小联合接口，则一次解释该接口的声明分量，不拆成虚构的纯 R/U。
独立 U 没有证据时，输出为真实 query、key 或候选评分的决定分量。

输入只来自已定位的原生路径。参照/关系标签可以分组评价，正确目标和答案不得成为替代函数
运行时的输入。独立定位数据可用于标定空间投影，但不能用关系答案逐图对齐坐标。

写清输出的分解：

`native_write = explained_part + unexplained_part`。

余项可能携带位置、关系和答案；保留余项不是证明它无关。紧凑模型只能领取其预测分量的
解释范围，不能将余项提供的条件信息计为模型已经恢复的计算。

## 数据与拟合顺序

1. M06 使用过的自然输入、干预及其结果全部列为 development，不重新命名为 test。
2. 先按场景族划分拟合与 validation；同图多问、换色、位置变体及其 donor/recipient
   关联不得跨划分。
3. 维度、正则和必要场景项只由 development/validation 决定；不要逐图重拟合。
4. 四对象六问已全部用于发现。新颜色、新族验证的是实例迁移，不是未探索参照—关系组合。
5. 在 [M08](M08_Local_Replacement.md) 的新原生响应被读取前保存模型、输入清单和预测；
   [M09](M09_Frozen_Prediction.md) 的 fresh family 与未拟合干预继续隔离。

所有近似都应同时报告原模型自然正确与自然错误的响应。若只解释正确子集，必须声明
覆盖与选择条件，不能把正确目标当作原生状态的替代真值。

## 原生输出、指标与操作判据

同时预测局部写入、全注意力响应与属性读取。至少报告：

- `write_error`：预测写入与实际写入的 L2 误差，另按自然条件变化的 RMS 尺度归一化；
- `score_error`：全部允许来源相对固定锚点的 logit 差误差；候选物体分差作为附加读数；
- `source_mass_error`：视觉、文本、特殊 token 总质量的误差；
- `head_output_error`：真实全分母下 pre-`W_O` 输出和投影写入误差；
- 颜色 margin、greedy 输出及自然错误预测；另报告按族分布。

自然变化尺度为零时不计算无意义的归一化比值，报告绝对误差及静态条件。
不能只用余弦相似度、高 R² 或最终答题率验收。

对每个复杂模型与较简单基线做**相同族、相同端口**比较。只有在 validation 上改善
答案相关的原生响应预测，并解决一个已定位的依赖缺口，才保留额外自由度。
若加性模型已解释该依赖，就不主张关系专属矩阵。高维模型只能记为拟合上界，
不以参数多、误差低作为机制优势。

## 接口重算与实现要求

离线拟合本身不改变原模型。预测分数和写入时必须使用相应自然/干预上下文的真实源端条件；
若变化的文本 K/V 未被模型解释，列为条件输入，不能声称 query 一项已解释整个选择。
共同地址空间只在主张自映射、逆关系或交换律时要求；不直接复合不同端口的矩阵。

进入 M08 前冻结实际替代边界、保留分量、norm/残差处理及下游重算范围。
若公式只是映射输出状态，不能直接当作原生组件“新增写入”替换。

## S / R / U / E 出口

- **S — 支持**：较小解释预测留出族的原生写入和条件响应，交付冻结函数与
  M08 原生干预响应预测；本节点仍不单独完成原生机制验收。
- **R — 反驳**：高拟合不能预测局部干预，或必须使用答案/每图自由基才能成立；
  撤回该紧凑假说，返回 M06 最早失败的依赖。
- **U — 不确定**：未解释分量可能承担关键条件信息，或静态数据不能约束函数；
  明确缺少的变化，不无条件增加维度。
- **E — 合并**：不同表达在相同输入范围、原生边与响应上不可区分；
  冻结最小等价描述及其适用范围。

## 工作量与停止条件

主要工作为已有捕获上的离线拟合，不默认新增模型前向。先登记候选模型数、每项参数量、
拟合样本/族数和 validation 规则；如需新增捕获，单列原因与数量。
每个候选只进行一次初拟与一次反例驱动修订；新增项必须带来不同的冻结预测。
仍需任意高维补偿则以 R/U 停止该候选，不靠再次调参消耗 M09 留出集。

产物为冻结参数、实际输入提取规则、替代端口、保留分量、逐配对原生响应预测和失败边界。
它们一并交给 M08，不只交一个平均拟合分数。
