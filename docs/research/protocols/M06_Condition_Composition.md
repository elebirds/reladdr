# M06_Condition_Composition — 参照与关系怎样形成候选偏好

状态：**计划；本节点专用流程未实现、未执行**。
入口为 [M05](M05_Selection_Carrier.md) 确认的控制载体/生产位置；
理论假说的统一定义见 [机制假说](../04_mechanism_hypotheses.md)，本协议只规定辨识步骤。

## 科学问题、简化基线与强竞争解释

恢复一段实际计算：

`参照绑定贡献 + 关系输入 → 局部条件写入 → 候选偏好 → 属性写入`。

先把共享映射加关系偏置作为低自由度基线，而非优先认定的原生算法。以 query 主导路径为例：

`q_hat = q_base + A B_ref + C E_relation`。

`B_ref` 是已定位的原生参照读取贡献，`E_relation` 来自实际关系输入路径；
二者不由正确目标标签代替。若真实数据要求交互，再比较关系调制映射
`A(E_relation) B_ref`。实际被解释对象优先是生产组件的写入 `m`，由原生残差、
归一化与投影继续生成 query；不得把完整状态都归给一个 MLP。
`q_base` 必须是预先定义的条件不变基线，或明确列出的未解释输入贡献，不能逐样本自由拟合
后吞掉参照/关系效应。保留的条件信息不计入已解释部分。

强竞争解释是方向选边界、上游已经选好的 payload、关系选择预存邻接字段，以及遗漏的
场景输入。组件可以是 attention、MLP 或短链路，不预设门控 MLP。

## 与紧凑假说同步进行的鉴别

取得候选生产端口后即与 [M07](M07_Compact_Explanation.md) 形成小循环，不等全部路径定位
或拟合失败。每批只选择当前最强的一对竞争解释，登记以下内容，再取得新响应：

- 两者使用的原生输入、输出端口和保留条件；各自如何解释已有自然结果。
- 一个让预测分开的合法场景变化或局部原生干预，以及写入、相关候选分差或属性效应的
  方向/幅度预测。优先复用已有自然对照；混合输入的兼容性另列。
- 能区分两者的观测及测量误差；若尚无分歧预测，说明缺少约束，先补该约束而非继续追头。

例如在**同一个生产写入端口**，对两份固定参照输入 `B0/B1` 与两份固定关系输入 `E0/E1`，
定义 `Δ = m(B1,E1)-m(B0,E1)-m(B1,E0)+m(B0,E0)`。加性模型预测 `Δ=0`，调制模型预测
`Δ=[A(E1)-A(E0)](B1-B0)`。这个比较要求同名输入在相应条件间保持相同，其余输入固定或
被模型明确纳入；局部输入交叉须说明实际端口及混合兼容性。自然运行的参照输入本身可能
随关系改变，此时应代入各次实际输入比较完整预测，不能把自然问题均值的非零交互直接
归给该组件。残差归一化后的下游交互也不能代替写入端交互。

场景鉴别同样由分歧驱动：在保持对象次序和“立即相邻对象”语义时改变间距，可检验已提出的
固定像素位移规则与序号邻接规则。先选出两规则确实预测不同候选偏好或写入的合法几何；
若后续取整/候选吸附使两者仍同预测，该条件无鉴别力。非等距本身不能区分序号运算与
邻接查表；要区分后两者，须给出不同的原生依赖/输入响应预测，否则保留未辨识结论。
这些用于选择解释的新场景归 development，不留到 V01 才做。

## 自然数据与输入辨识

使用 B03 内部参照×左右关系 factorial 与 M04 的局部换色。保留六问发现结果和所有错误，
主读取链可用自然基线正确子集作因果锚点并报告覆盖；错误按 M04 的输出可定位性另列。
参照移动、身份换位和换色变体属于同一场景族。

从消费端沿 M05 的有效来源反查：

1. 参照描述改变如何改变实际绑定的视觉贡献；同身份换位置与同位置换身份区分身份和空间。
2. 关系改变通过哪些原生输入边到达生产组件；关系前的状态不能包含尚未出现的当前关系，
   但可能包含所有方向的预存字段。
3. 固定参照贡献时，关系输入变化如何改变局部写入；固定关系输入时，参照贡献变化如何改变写入。
4. 上述变化是否预测真实候选偏好、来源注意力总权重与属性写入。

混合输入用于检验预先声明的局部预测，结合自然配对解释。预测始终沿模型的实际输入进行；
绑定错误须有输入路径证据，不能只由答案颜色倒推。真值参照坐标不得替代原生输入以“校正”解释。

## 端口与重算

登记实际视觉来源的头输出、关系路径的 attention/MLP 写入、生产组件输入/输出及消费端。
若将 pre-O 来源贡献经 W_O 映射到残差空间，明确记录这一步；再作空间投影时保留余项，
投影空间和余项均可能携带条件信息。不同物理空间的向量不能直接相加。
局部输入/写入替换后重算所有受影响下游，含 RMSNorm、残差与后续注意力。
不以孤立 MLP Jacobian 代替跨层路径；JVP/VJP 仅用于已定位路径且能改变判断时。

完整来源参与注意力归一化；输出记录声明候选分差、来源注意力总权重、pre-`W_O` 输出与
实际属性写入。未解释分数/来源可保留原生值，但须列为条件输入，不能算入已解释贡献。
“候选间分差相同”不足以建立包含其他来源的整行计算等价。

## 三个按证据启用的条件分支

### `scene_conditioning`：额外场景输入

**触发**：同一参照/关系成分不能预测写入，而某条已观测场景路径解释残差。
固定主要输入、对该路径做自然 donor 对照，检查是参照读取、候选 key 还是组合组件
引入场景条件。只加入有实际路径的输入；不逐场景自由换基、不直接拼整张图高维状态救拟合。

支持出口需预测该路径变化对写入/评分的方向和幅度。若归一化或排序是必要步骤，它本身
进入解释；不能作为每图独立标定的隐含自由度。

### `precomputed_neighbors`：预存邻接字段

**触发**：视觉前缀或独立证实不受当前关系影响的源成分携带候选邻接信息，且 M05 显示该来源被消费。
不要求关系先行模板的参照词处也存在一个“关系到达前”的绑定状态。
这仍未确认字段读取；仅 probe 可解码而没有来源使用证据时不启用该分支。
比较实际源端字段变化与关系选择响应，检验该信息是否在在线候选读取之前形成并被消费。
选择性字段干预须与相应关系响应对应；搬运整个参照状态不能命名为字段选择。

固定完整网格上的邻接表可写为地址置换，可能与在线线性变换在该域严格等价。
只有写明输入域、原生依赖、允许干预以及完整输出，并证明两者预测相同，才合并为该范围
内的解释类。未找到鉴别条件时记录“当前证据不足以区分”，不据此断言等价。

### `parallel_and_backup_routes`：并行与备用路径

**触发**：单条路径无法解释自然效应，或干预后出现新的来源贡献。
先区分自然执行已存在的联合贡献，与破坏主路后才增加的来源；仅对观测到的共同路由
进行联合检查，不把所有路径做全组合删除。

无单路删除效应不证明未使用；只在损伤后恢复的路线不称正常主路。
若证据支持稳定的联合贡献，紧凑解释以该联合接口为范围；无需先证明它是全网络最小接口。
各路共同起作用是正面路径结果，不意味着各路彼此等价。

## 指标与可操作判据

对每条候选路径报告：

- 真实参照/关系输入的自然效应、局部写入效应及两因素交互；
- 局部预测误差相对自然旧→新变化的尺度，及固定关系/固定参照基线的误差；
- 声明候选分差、来源注意力总权重、OV 写入与属性 margin 的逐配对响应；
- 已解释与未解释路径的效应，按族汇总，不能只报告答对子集。

支持组合解释要求：两类真实输入均经声明路径产生可预测的中间变化，并且关系/参照固定
对照可排除方向选边界或纯 payload 搬运。额外项只有在改进留出预测且对应真实依赖时保留。
自然误差小、但局部干预效应预测错误时，分别检查函数形式、遗漏依赖和混合兼容性，
不以更高拟合度覆盖失配。

## 结论与下一步

- **组合路径得到支持**：闭合到输入、组合、评分和属性消费，向 M07
  交付待压缩的局部函数、真实输入清单、替代边界和未解释分量。小循环中的暂定函数可更早
  交给 M07 产生鉴别预测，但未闭合部分继续标为待定位。
- **联合贡献得到支持**：多位置/多头输入共同解释自然响应，按联合接口进入 M07，
  分别记录各路及交互效应，不将共同有效命名为机制等价。
- **具体解释被反驳**：边界策略或上游 payload 足以解释，或拟议写入无法预测条件响应；
  撤回具体运算命名，保留已经证实的路径。
- **证据不足以区分**：实际依赖尚未分离、效应小于测量分辨率，或当前比较同预测；
  明确缺少的边/约束以及能改变判断的下一预测。
- **限定域内等价**：依上述完整接口约束证明不同表达给出相同依赖与响应，
  以该域的等价类进入 M07；结论不外推到未声明的场景或干预。

## 工作量、回溯与批次停止

开始前列出消费端到实际参照/关系输入的待核查有向边、自然配对数 `P` 和每边条件数 `I_e`；
预计干预前向为 `P × Σ_e I_e`，捕获与校验另列。三个分支按触发条件启用，不默认并行全跑。
每批登记上限和实际成本；继续投入须给出新证据或不同的可检验预测及其预算，
不能因还有算力而自动扩展网络范围。预算用尽只暂停执行，不构成科学反证。

闭环到**真实参照绑定输入、真实关系输入、组合写入、候选偏好、属性消费**即可停止。
不需要追到全网络最早可解码状态，也不要求先解释整个视觉编码器。
冻结后出现反例时，只回到最早预测失败处；已通过且输入条件未变的链段不重扫。
