# V01_External_Validation — 同一机制的外部边界

状态：**计划；未实现、未执行**。前身为阶段规划中的 E05，旧编号不代表已经有验证结果。
依赖 [M09](M09_Frozen_Prediction.md) 支持的冻结解释或限定域等价类的共同计算预测；
若核心计算仍未解释，返回对应 M 节点。

## 科学问题与竞争解释

冻结解释是否只依赖合成图中的颜色、网格或提示捷径？新条件的变化由同一计算预测，
还是模型切换了不同路径？首选一个能区分这些解释的外部边界，不同时铺开多数据集/多模型矩阵。

用于区分核心竞争计算的场景变化在 M06/M07 的发现小循环中完成；本节点检验已经冻结的
计算如何迁移或失效，不等到这里才消除固定位置域的未辨识问题。每个新增条件对应一项明确预测，
例如场景相对编码对整体平移的响应、候选竞争对干扰对象的响应，或已定位归一化的失效。
没有不同预测的外部变化不进入本轮。

## 外部输入的选择与语义核查

优先沿现有 R3/What'sUp 研究积累，核查是否有适合“参照 + 关系 → 未知目标 → 属性”的
可用构造和标签。不能默认公开关系分类数据已经具备唯一目标及颜色真值。
若需要补标，先定义参照唯一性、空间关系语义、目标及属性标签，再决定数据是否适合。

COCO-spatial 等给定两对象判断关系的任务只能作为补充边界，不能替代本项目的目标选择。
“直接相邻格”“最近对象”“同侧任意对象”分别定义；语义不清样本按预定规则处理，
不能事后选择符合预期机制的图片。

同原图及其翻转、裁剪、换色和多问属于同一族。保留全部自然基线结果；正确子集的因果结论
另列覆盖，感知/绑定失败不能被直接归为关系执行失败。

## 端口、重定位与冻结条件

同模型、同接口且输入处理未变时复用有效端口证据，只核查实际 token 映射和新增来源。
processor、图像分辨率或序列布局改变时，先核查受影响的映射、mRoPE、来源集合和重算范围。
保持全来源 softmax 与 OV，不把新图上的 bbox attention 当作目标选择真值。

第二模型仅在同一机制提出可检验跨模型预测时加入。允许重新定位物理层/头及合法坐标基，
但必须用独立定位数据完成，再冻结测试；不能在每个测试样本重新对齐后称共享机制。
若必须改变核心输入依赖或计算函数，记为机制变化，而不把重拟合结果算作原解释迁移。

## 操作与指标

先按冻结规则提取真实输入，隔离待评估的下游响应，再保存对声明写入、相关候选竞争/
来源注意力总权重、属性读取及错误的预测。完整归一化保留，未解释来源的条件输入按原声明记录。
先测自然执行，再只执行能检验该预测的局部干预/替代。复用 M07–M09 的中间量与实际 greedy
指标，另列外部域自然能力、绑定错误和解释覆盖。

主要比较：

- 冻结解释与其最强简化/竞争基线在相同外部族上的原生响应预测；
- 旧路径与新出现路径的自然贡献；
- 模型回答正确但中间解释错误，以及模型回答错误但解释正确预测失败的位置。

外部答题率上升不是本节点成功标准。核心是同一机制能否预测新条件的因果响应，
以及失效是否落在预先给出的边界。

## 结论与范围修订

- **外部预测得到支持**：冻结解释预测外部自然/干预响应，或准确预测明确的失效边界；
  将范围与证据纳入论文贡献。
- **外推被反驳**：外部响应要求不同的核心计算；收缩原机制适用范围，记录替代机制的证据。
  不撤销仍被原域证据支持的结论。
- **证据不足**：任务语义/标签不可靠、自然能力不足以区分机制，或定位数据与测试混用；
  修复对应数据/接口条件，不靠增加模型数量解决。
- **竞争解释未分开**：保留未辨识结论；只有已有等价证明的约束覆盖新域及干预时，
  才沿用原等价类。外部样本上同预测不足以扩大其等价范围。

自然执行的联合贡献仍按联合接口报告；若只在干预后出现新路线，则收缩原路径的迁移结论。

## 工作量、授权与停止条件

先完成数据/标签的只读核查，再按选定域登记族数、自然输入数、必要干预数和存储量。
新增数据/权重下载、付费计算或远程服务操作遵守项目授权规则；本协议不构成执行授权。
第二数据域或第二模型不是默认下一步，只有第一边界留下不同的关键预测时才单独立项。

一个外部边界回答了冻结机制的适用性问题即可停止。若仅能反复展示相同答案翻转，
而没有新的计算预测，结束本节点并写明证据范围，不继续扩展展示性条件。
