# M05_Selection_Carrier — 选择条件的实际载体

状态：**计划；本节点专用流程未实现、未执行**。
依赖 [M04](M04_Attribute_Readout.md) 的功能接口；端口检查复用
[M03](M03_Native_Instrumentation.md)，不把既有整状态 patch 当作本节点结果。

## 科学问题与竞争解释

同图改参照或关系后，M04 的属性接口为何读取另一个对象？

- `query_control`：query 改变相同候选记忆上的竞争。
- `key_routing`：文本 key 改变有效来源的路由。
- `selected_payload`：上游已把目标/答案写进文本 value，当前接口只是读取。
- `joint_carrier`：评分与内容共同变化，单一张量不构成独立选择接口。

本节点定位承载条件效应的路径，不以“Q 能翻转答案”结束机制研究。

## 数据与必要控制

使用 B03 的同图自然问题组。先取仅关系改变、再取仅参照改变的有向配对，完整记录问题、
实际 token 位置、旧/新参照与目标。真值角色重叠保留并标记，不能由旧参照颜色输出直接推定
新目标被正确选择。局部换色对照沿用 M04，帮助区别搬运属性与改变选择。

四对象六种合法问题全部属于发现域；后续新族不称未见问题组合。自然错误保留，正确子集
单列覆盖。先冻结有向配对列表和载体预测，再查看交叉结果。

## 原生端口与重算范围

在 M04 的读取器获取自然问题 0/1 的 `Q,K,V`，区分视觉、文本、特殊 token 来源。
同图同前缀的视觉状态固定；文本 K/V 可以随问题改变。Q/K 的 pre/post-mRoPE 状态、
GQA 原生 KV 头和全部受影响 query 头必须按 M03 契约登记。

每次局部干预使用原生 mask 与**全部允许来源共同参与的 softmax**，重算该组件输出及
所有受影响的后续状态。K/V 若为共享原生槽位，不能只改一个复制品却声称修改了原生槽位。
若仅替换特定 query 行的分析性 attention 输出，必须标为行级局部写入干预。

先比较两种交叉：

1. `new_query_old_memory`：`Q1,K0,V0`。
2. `old_query_new_memory`：`Q0,K1,V1`。

只有第二项显示有效内容/路由变化且影响下一步选择时，才追加 K 与 V 的分离。
其他状态保留哪个自然上下文必须明确，不构造未声明的全后缀混合。
交叉状态未必自然可达；成功不等于原生使用该算法，失败不等于该载体不存在。

## 中间量与可操作判据

同时记录：

- 全允许来源相对同一锚点的 attention logits，及有因果依据的候选来源间分差；
- 视觉、文本、特殊 token 的 attention 总质量与实际加权 value 贡献；
- pre-`W_O` 输出、局部残差写入、下游颜色 margin 和 greedy 输出；
- 干预后是否产生自然运行中没有的来源或路径变化。

只比较视觉候选内部 softmax 不充分。视觉 logits 同加常数不会改变视觉内部相对权重，
却会改变视觉相对文本的总质量。若候选物体对应多个/分布式视觉 token，先保留真实来源
贡献，不用 bbox 内 attention 总量替代对象选择真值。

将交叉响应与自然旧→新变化比较：报告效应方向、幅度、尚未恢复的写入/来源质量。
只有当条件载体能预测自然变化，并且定向交叉沿相应路径产生预期中间响应时，才进入对应
支路。仅输出颜色命中、或仅条件分差恢复，均不足以宣称完整读取效应被解释。

## S / R / U / E 出口与优先级

- **S — 支持**：Q、K、V 或小联合接口承载效应，且来源/写入对应；
  把具体生产位置交给 [M06](M06_Condition_Composition.md)，优先解释它怎样形成。
- **R — 反驳**：当前接口只读上游已选 payload；撤回此处“执行关系选择”的命名，
  沿有效源端追踪生产位置。
- **U — 不确定**：交叉不兼容或仅行为变化。使用同一自然记录和已定位局部写入回溯，
  不通过扩大整状态移植来宣布载体。
- **E — 合并**：Q 与文本记忆共同构成稳定接口，或不同张量写法产生相同原生依赖与响应；
  保留联合接口进入 M06，不强求单 token/单向量充分。

## 工作量与停止条件

设 `P` 为冻结的有向配对数、`C` 为 M04 保留接口数。首轮两种交叉需要 `2PC` 次干预前向；
缺少的自然捕获、接口检查另列，现有有效捕获不重复获取。K/V 分离最多增加 `2PC`，
且只对会改变判断的接口启用。不做全层×全头×全部混合组合。

定位载体即停止本节点，M06 承担参照与关系的计算解释。每个候选最多一次反例驱动的
源端重划分；仍无法区分则交付 U 与具体联合依赖，不无限回溯“更早的 Q”。
