# M05_Selection_Carrier — 选择条件的实际载体

状态：**计划；专用流程未实现、未执行**。依赖 M04 的实际消费者和
[M03 reader_attention](M03_Native_Instrumentation.md) 的针对性观测／重建。
默认操作是声明行／头组的 **pre-O 合成输出写回**，不是原生 K/V 节点替换。

## 1. 先写竞争预测，再执行交叉

同图改参照或关系后，消费者如何改读另一个对象？主要比较：

- `query_control`：变化的 query 在原记忆上改变候选偏好及读取写入。
- `memory_carrier`：变化的文本 key/value 提供路由或已选 payload，query 变化不足以解释。
- `joint_carrier`：两侧共同参与；混合上下文可能不兼容。

在看交叉结果前，对声明输入写出各解释的**不同预测**：相关候选对比、来源注意力总权重、
pre-O／W_O 写入及下游颜色 margin 会向哪种自然响应移动，哪些分量预期保持。
最终颜色可能受其他 recipient 状态限制，不能只用“是否输出 donor 答案”判别载体。
若该配对上的预测不能分开，先改选有明确分歧的比较，不执行后再宣称二者等价。

主要消费者若为 MLP，追其实际输入或供应信息的 attention；当前流程不把 MLP 输出当作 Q。

## 2. 数据、方向和可对齐范围

使用 B03/M04 发现域的同图自然问题对，优先同参照改关系，其次同关系改参照；同目标配对
用于控制目标不变的条件变化。保留成功／错误样本的定义、覆盖及实际输出对应对象假说。

每个有向配对明确 `0=recipient`、`1=donor`。两种交叉都使用自然问题0的完整上下文。
逆方向另建有向配对，不暗含在两种交叉中。颜色 donor 与语义 donor 分别标记。

第一轮只取实际长度、物理位置编码坐标、可见 mask 可逐位置直接对齐的配对，保存对齐表
并报告排除覆盖；文本 token 内容可以不同。post-mRoPE 值直接用于同坐标，不二次旋转。
需要跨位置重映射时另立端口和预测，不静默平移 donor。

## 3. 默认干预的精确定义

接口 C 是同一层的声明 query 行集合 T 与 query-head 组 H；多位置／多头允许联合写入。
不同先后层不能合称一次局部交叉，否则后层的自然张量可能覆盖前层的因果后果。

从两个自然运行取得实际 post-mRoPE Q/K、V。使用原生 GQA 映射 g(h) 和 recipient0 的
全局有效行 mask m0：

\[
\widetilde y^{Q}_{t,h}=\operatorname{Attn}(q^1_{t,h},K^0_{g(h)},V^0_{g(h)};m^0_t),
\qquad
\widetilde y^{KV}_{t,h}=\operatorname{Attn}(q^0_{t,h},K^1_{g(h)},V^1_{g(h)};m^0_t).
\]

分别登记为：

1. `row_output_new_query_old_memory`；
2. `row_output_old_query_new_memory`。

每次只将对应合成 y 写入 **recipient0 的同一 pre-O 行／头组**。同层其他行和头保留
recipient0 原值；由原生 W_O、残差、同层 MLP 及后续层完整 no-cache 重算。
此操作不改变原生 K/V 槽位，同层其他共享 KV 的头不会自动改变。

局部 attention 保留全部允许 key，不在视觉对象候选内重新归一化。抽取 query 行后必须
materialize 其真实全局 causal/padding mask，并令局部算子 `is_causal=False`；不能对
`[1,K]` 直接使用按局部行号生成的三角 mask。GQA 是取共享的原生 KV 头，不复制出独立干预槽。

若第一轮的自然与交叉响应显示 K/V 区分会改变判断，再用同一 recipient、同一 pre-O 端口
检查 `Q0,K1,V0` 与 `Q0,K0,V1`，仍命名为 `row_output_`。节点级 K/V 替换另名 `native_node_`，
其所有共享头／读取行的影响及重算范围见03/M03；两类结果分别解释。

## 4. 指标、数值控制与最小首测

同时记录自然0/1、重建自写和两种交叉的：

- 声明相关候选间分差／偏好，以及用于完整归一化的来源集合；
- 视觉、普通文本、特殊 token 的来源注意力总权重与加权 value 贡献；
- pre-O、W_O 写入、下游颜色 margin、实际 greedy；
- 相对自然运行新增的来源／下游路径变化。

完整分母必须正确；无需把解释范围外的每个背景 token logit 都拟合成一个小模型。
若保留的文本 K/V 承担未解释条件信息，明确标为条件输入，不把它算进 query 的解释贡献。

首个定向比较优先复用 M04 已保存的两端完整 logits 和该接口原生 y。计划七次尝试，顺序为：

| 顺序 | 操作 | 次数 |
| --- | --- | ---: |
| 1 | 两端自然前向补 Q/K/V 观测，与 M04 基线比对 | 2 |
| 2 | 重建 y000 写回 recipient0；y111 写回 recipient1 | 2 |
| 3 | recipient0 无 hook 恢复 | 1 |
| 4 | 上述两种交叉，均写入 recipient0 | 2 |

原始 y 自身替换属于严格 no-op；重建自写测量数值近似的下游影响。已有有效原始自写证据
可复用；没有时另外计入检查。不能把 y111 写入 recipient0 当作重建控制。

捕获／恢复失败、重建误差掩盖分歧，或预测无鉴别力时，不继续最后两次交叉。
交叉效应同时对照 recipient0 原生和重建自写基线；效应方向随基线改变时报告数值不确定，
不用减去误差标量来“校正”机制效应。所有重建／落盘耗时也计入成本。

## 5. 结果怎样改变下一步

- query 的自然变化和行级响应符合预测：优先追 query 的实际形成过程，进入 M06。
- K/V 载体符合预测：区分路由与已选 payload，再追其生产位置；当前消费者不冒称关系执行者。
- 两侧或多个位置共同有用：以联合接口继续，记录已识别依赖；这不是组成路径彼此等价。
- 自然变化与交叉不符：检查兼容性、未解释输入和受影响下游；不以零 patch 证明该侧无作用。
- 当前数据无法区分：登记缺少的比较；只有明确域内依赖与干预预测相同的论证才能合并解释。

得到有依据的载体后，下一项是“动态参照和关系怎样生成它”，而非扩大 Q/K/V 组合矩阵。

## 6. 成本与批次边界

P 为登记的有向配对数，C 为冻结局部接口数。默认交叉成本准确为 `2PC` 次 recipient 前向；
缺失自然观测、重建控制／恢复和失败调用另列。反向配对增加 P，K/V 分离另增 `2PC`。
首个 `P=C=1` 比较的七次账本只是当前批次分配，更多接口须说明新增鉴别价值和成本。
资源不足可暂停，技术修订次数和候选数量不作为科学成败判据。
