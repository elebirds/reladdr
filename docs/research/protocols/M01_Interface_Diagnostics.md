## 已执行的问题与三标签契约

固定逐字相同的问题、同关系及参照身份，在图中移动参照，检验 B02 的响应是否仅搬运方向。
区分接收图原答案 a、接收图 donor 目标位置颜色 b、donor 原答案 c；三者必须不同。
实际 greedy 输出 b 才计位置迁移；候选拼写聚合概率另外记录。全量及双端正确子集分别报告。

端口为零起点 decoder block-post 0–27；readout 是追加 assistant generation prompt 后物理末位置（换行），
不是图示 is。`text_suffix` 包含 vision_end、问题、user/assistant 边界和生成标记，不替换实际视觉 token。
每次完整 no-cache prefill；从被替换层后重算原生网络。完整序列 donor 替换、自身替换、移除 hook 恢复检查
仅确认端口一致性；已有有效检查可复用，新执行条件变化时重新验收。

## 历史 case 与不可更改的语义

| case／协议版本 | 数据和操作 | 对结论的约束 |
| --- | --- | --- |
| `linear_directional` / `e03a-v1` | discovery 8族16对；中间参照移到合法边缘；不含 immediately | 边缘同侧多个对象有歧义，只作诊断 |
| `linear_adjacent` / `e03a-v2` | 同图像、配对与标签，双方提示加 immediately；readout／问题末词曲线 | 正向 b 总等于接收图参照色，不能独立否定地址 |
| `reverse` / `e03a-v2` | 反转 donor/recipient；只依三标签真值保留13对，保存排除清单 | 不按模型对错或干预效果选择配对 |
| `suffix` / `e03a-v2` | 相同16对，多位置完整后缀替换；保留28层曲线 | 后缀成功可搬运场景／参照证据，不保证纯目标地址 |
| `grid` / `e03a-grid-v1` | 2×2、336px、56px方块、144视觉token；每族四方向；discovery32对，validation/test各16对 | a/b/c/参照色四者不同，c不在接收图；b不在donor的真值切片另列 |

二维同关系移动参照到另一合法行／列，donor目标不是接收图原目标或参照格；图像束不跨族／划分重复。
冻结配置同时保存17/21层及readout/suffix，不在test重选峰。线性冻结保留原全层曲线。
B02 同措辞对照、反向和后缀对照均保留，不用二维正例抹掉线性失败。

## 已完成证据怎样影响现在

同指令、二维去重叠条件下的 b 正例，不能由“只搬运了被更换的方向词”解释；
它仍可能搬运用于下游重算选择的参照／场景证据，没有恢复关系算法。
一维角色混淆不能否定地址；二维成功也不能把全残差直接命名为 U。
同层端口差异支持检查联合状态，不能把混合恢复中的位置依赖升级为自然执行必要性。
详细当前判断见 [07](../07_outcomes_and_decisions.md)，不以此旧节点的完成声称 M06 已完成。

## 条件性辅助 case：address_relay（计划）

**问题／竞争解释：**已定位选择状态能否跨上下文控制位置，还是携带属性、场景兼容信息？
只有原生路径已经提示可迁移状态，且论文需要该主张时启动；不是 M06/M07 的依赖。

**端口／重算：**生产端局部状态接入独立图像的冻结读取端；保留明确的非替换分量，重算接收端全部下游。
先声明兼容域，不将任意整状态视为地址，不用逐场景自由换基补救。

**数据／控制：**独立场景族标定读取端，位置与颜色解耦；标定数据不用于评价生产端。
原生消费者与中继对同一局部变化须给出可比较的位置预测。不得根据生产端成功率反复优化中继。

**指标／出口：**原生位置作用、中继位置响应、颜色泄漏和适用覆盖。
支持则增加跨上下文语义证据；失败只撤回该端口的可迁移性；混合不兼容归 uncertain。
若与已有原生读出无新增可区分预测，则 equivalent 并停止。一次预定标定＋留出后仍需不断调读出，就停止该case。

**依赖／预算：**低优先级，依赖 M06 的实际接口；尚无执行预算，不在首批授权范围。
若触发，先冻结族数和标定次数，按 [08](../08_resources_and_reproducibility.md) 的调用公式提交独立预算。
