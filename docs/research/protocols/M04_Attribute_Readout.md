# M04_Attribute_Readout — 属性从哪里写入

状态：**计划；专用流程未实现、未执行**。复用现有 pre-O 逐头和 MLP 写入端口；
先做针对性验收及局部确认，再为选定消费者补 Q/K/V 观测。
数据所有权见 [B03 v2](B03_Reference_Disambiguation.md)，本批名额和成本只在
[08](../08_resources_and_reproducibility.md) 登记。

## 1. 科学问题：写入传递的是哪个对象的属性？

定位将对象颜色传入下游的原生写入，并区分真值目标读取、错误对象读取、一般配色响应。
只有正确答案时，原协议的“目标／非目标换色”才足以给出清楚的第一对照；错误输出需要
区分以下三种角色：

- `truth_target = g`：问题的真值目标，由图像语义决定。
- `output_linked_object = o`：原始 greedy 颜色在本图中唯一对应的对象，是**待检验的读取候选**。
- `control_object = k`：本次被检查角色之外的非参照对象。

即使答案正确，`o=g` 也不单独证明内部读取了 g。自然换色是否跟随该对象，以及局部写入
能否传递相应颜色变化，才检验读取解释。attention 在目标框上或写入范数大只用于定位线索。

## 2. 从完整行为结果中选择锚点

使用 B03 v2 的全部 9 族、两配色、六问；先保存全量结果，再按以下规则选择，不查看 patch 效果。
首批名额是资源分配，不是科学成立所需的固定样本数。

**成功锚点优先使用配对。**按 B03 六类配对的登记顺序，依次在尚未使用的 family 中取
`(family_id, palette_id)` 字典序最先的双端 greedy 正确配色。循环直到本批配对名额用尽
或候选耗尽。每个成功配对的两条输入一起捕获，方便后续比较参照／关系变化。
实际不足时保留较小集合，不为凑数换模板。若没有合格配对但有单题正确，可按
`family_id, palette_id, question_index` 取单题锚点（每族至多两条），其后不冒充配对证据。

**错误诊断另列。**在 greedy 为图内唯一颜色且 `o≠g、o≠reference` 的输入中，
优先取成功锚点未用的族，再按上述字典序；每族取一条，直到本批诊断名额用尽。
它们不与正确锚点合并成一个“读取成功率”。

输出等于参照色时记为 `reference_output`；图外颜色、无效 token 或非唯一映射分别记录。
本协议保持参照颜色和问题不变，不能直接给参照换色来检验其读取；这些情况留在全量行为报告中，
要研究时另写保持绑定可解释的对照。没有错误样本时报告实际覆盖，不人为制造错误配额。

报告每一步候选数、选择结果、独立族数、自然准确率及选择覆盖。正确子集是允许的因果锚点；
其结论范围由该选择条件限定。

## 3. 派生输入：先赋所有权，再按角色去重

每条锚点保持原几何和完整问题。使用原图未用两色，按 `PAPER_PALETTE` 顺序记为 `unused`；
替换色固定为 `unused[(family_number + question_index) % 2]`，同锚点各变体共用此颜色。
所有变体都落在 B03 已预留的单换色闭包内。

| 锚点 | 检查对象集合 | 对照对象 k | 自然输入数（含 base） |
| --- | --- | --- | ---: |
| 正确，o=g | g、k | 排除 reference、g 后最小索引 | 3 |
| 错误，o 为非参照对象 | g、o、k | 排除 reference、g、o 后最小索引 | 4 |

若多个角色／问题构造同一图，复用 `image_id`；只有完整图像＋提示相同才复用 `input_id`。
同一输入的重复捕获仍耗用前向，记为重捕获而非新自然输入。执行前对整批实际锚点和派生
输入做最终所有权核对；不能沿用旧“48次”或“32个新增输入”的常数。

每个变体重新记录真值、greedy 及其在该变体中的对象映射。若换色后答案改指其他对象，
记录选择变化，不直接把它称为稳定读取同一对象的属性跟随。

## 4. 首轮使用已有写入端口

在 [M03 的 consumer_write](M03_Native_Instrumentation.md) 通过针对性检查后，
完整 no-cache 自然前向捕获各 decoder 层的实际后缀 pre-O 头输出和 MLP 写入。
后缀包含 vision_end、assistant 标记，readout 为 generation prompt 后的物理末位置。

保存原生 y、对应头的 `W_O[:, I_h] y`、MLP 写入、完整末位置 logits、greedy、候选概率和
新旧颜色 margin。张量按实际后续分析需求分批落盘，不要求常驻全层注意力矩阵。
**此轮不要求来源分解。**确定读取候选后，M03 的 reader_attention 才补 post-mRoPE
Q/K、全来源权重及 value 贡献；未取得的来源注意力总权重不作推断。

原有 hook 清理和自身替换证据按适用条件复用。只有消费者需要的新能力才验收，逐 Q-head／
KV-head 投影干预不是本节点前提。

## 5. 从自然候选到局部功能确认

先比较角色换色引起的实际写入变化与颜色 margin：

- 成功锚点：g 换色效应与 k 换色效应对比。
- 错误锚点：分别比较 g、o、k；主要响应 o 而非 g 可以支持错误对象的属性读取，
  不能因它是真值“非目标”就撤回候选。
- 若只响应一般配色，或自然变化不能对应任何待测角色，保留为未定位候选。

自然分析后，在查看干预结果前登记候选接口、角色预测和选择依据。一个接口可为同层多头／
多位置，或 MLP 写入；不要求单头充分。接口数量按本批调用额度分配，更多候选需明确新增鉴别价值。

局部确认固定 recipient 为该锚点的 base，donor 为对应单对象换色自然输入。
只替换声明的 pre-O 行／头组或 MLP 写入；由原生 W_O（若适用）、残差、同层剩余组件与
后续层完整重算。对每个候选执行该锚点的全部角色变体：正确锚点两种，错误锚点三种。
相同接口和替换范围用于角色对照，不随颜色效果改变。

在看结果前写出：若该接口传递 o 的颜色，o 换色 donor 应把新／旧 o 颜色 margin 向新色推；
仅 g 或 k 换色 donor 的响应应按竞争解释不同。输出变色若由一般颜色注入同样解释，
不能据此认定对象特异读取。记录方向、幅度、未解释效应，区分自然换色与局部混合状态。

## 6. 结论与后续动作

- **角色特异写入得到支持**：自然变化与定向局部响应一致，将实际接口和成功／错误覆盖交给 M05。
- **错误对象读取得到支持**：保留读取功能，下一步定位造成选择错误的上游条件。
- **一般配色／答案注入更能解释**：撤回对象特异命名；回到有不同预测的来源或组件。
- **联合贡献**：多个位置共同恢复效应时，以联合接口继续；这不是头之间“等价”。
- **尚不能判断**：自然效应与混合响应不一致、数值误差过大或没有足够角色变化时，写清缺口。
  继续投入根据新增证据或区分预测，不按修订次数宣布失败。

若主要消费者是 attention，优先进入 M05 的一次定向载体预测比较；若是 MLP，则追其实际输入，
不为套用 Q/K/V 交叉而丢掉 MLP 结果。初批结束应交付一个有证据的消费者候选，以及最强两种
解释在下一项原生响应上的不同预测；仅排序重要头还不足以推进组合解释。

## 7. 工作量

设去重后成功单题锚点数为 N_c、可处理错误锚点数为 N_e、注册接口数为 C。
自然捕获上界 `3N_c+4N_e`，其中 base 重捕获 `N_c+N_e`，新局部换色至多 `2N_c+3N_e`；
局部确认前向为 `C(2N_c+3N_e)`。实际重复输入从新输入项扣除，缺失激活单列重捕获。
工程检查与 M05 首测另外计账，具体本批分配以 08 为准。
