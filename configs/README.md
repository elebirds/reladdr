# 实验配置约定

可运行配置与对应的运行入口一起加入。目前没有实验 CLI，也不提供看似可运行的占位 YAML。
每个实验配置描述一次可复现执行；方法之间只改变比较所需字段，其余条件保持一致。

## 配置应包含的部分

| 部分 | 必须明确的内容 |
| --- | --- |
| 实验身份 | 实验编号、研究线、方法、seed、输出位置 |
| 数据 | 数据集及生成器版本、场景族、关系语义、split ID、场景分组规则 |
| 模型 | checkpoint 与固定 revision、processor revision、dtype、attention backend |
| 图像 | 实际预处理规则、视觉 token 预算；不能只记源图像像素大小 |
| 机制分析 | 候选层/头、读取位置、子空间维度、拟合和超参数选择所用 split |
| 干预 | 接口、pre/post-RoPE、原生 KV 头/槽位、分组、固定 donor 及位置对齐规则 |
| 集合搜索 | 大小 k、固定问题权重与 foil、停止规则、真实下游调用/时间预算 |
| 记录 | local 或 mlflow、experiment 名称、允许上传的产物类别 |

多问题共用一个图像时，以 scene ID 为最小划分单位。原图、镜像、换色和其他成对变体
共用同一个 scene-family ID，不能分散到拟合和最终测试两边。

运行时将实际展开的配置保存在该 run 目录；敏感变量只记录“是否提供”，不记录值。
模型 revision、dtype 或干预单位变化后，应生成新的运行记录，不能沿用旧缓存的结论。
