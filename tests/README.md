# 测试随真实功能加入

当前只有包结构，没有实验实现或占位测试。基础 CI 检查依赖、格式、包导入与构建。
在没有测试文件时，pytest 的“未收集到测试”不代表测试通过。

## 第一批实现对应的测试

1. **场景和问题**：目标唯一；行列/方向定义一致；边界与空位按声明处理；答案与标注一致。
2. **数据划分**：同一场景及其反事实变体不会跨 discovery/validation/test 泄漏。
3. **模型映射**：processor 后的视觉 token 与图像区域、GQA 分组、位置编号一致。
4. **干预语义**：未干预和 no-op 替换保持输出；异常退出后 hook/cache 恢复；只改变声明端口。
5. **解析响应**：小型数值实例及少量原生接口上，解析完整注意力输出与实际重算相符。
6. **集合求解**：小规模穷举核对代理值、可行性、下界和间隙；真实行为指标单独计算。

纯数据/代数测试应可在 CPU 上运行；模型依赖与 GPU 检查显式分开。不要为通过 CI
临时下载模型。相关测试与真实模块一起加入，后续再启用 pytest 的 CI 步骤。
